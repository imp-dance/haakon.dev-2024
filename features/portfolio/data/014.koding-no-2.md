# Relaunching Koding.no

![Koding.no frontpage](/koding-no/1.jpg)

After the Neddi project, I have been focused on developing Koding.no into a full-fledged course platform for the Norwegian audience, with the aim of
creating an engaging and fun place for people to learn how to code, both in school and in their off-time. The mantra is "Learn it by making it", which we achieve through interactive exercises and projects as well as structuring our courses so that the student ends up _building_ something.

## Features

- **Courses with rich interactivity**
  - Exercises, playgrounds, assignments, visualizations, animations, quizzes, context aware ai helper
  - ![Interactive koding.no lesson](/koding-no/2.jpg)
  -
- **Community integration**
  - Share progress with your groups, follow others and react to progression, challenge eachother and compare XP gains
  - ![Screenshot of community page, feed of posts and reactions](/koding-no/4.jpg)
  -
- **Gamification**
  - Unlock achievements, hats, titles and XP. Customize your public or private profile (koding.no/@username)
  - ![Screenshot of profile and hat-change](/koding-no/10.jpg)
  -
- **Internal authoring interface**
  - Lets us visually create and edit courses for the website, configure exercises, quizzes, and move blocks around
  - ![Screenshot of authoring platform](/koding-no/7.jpg)
  -
- **Feide integration and school licenses**
  - Multiple user roles (personal accounts, students, teachers, school administrators)
  - Teachers can enable or disable certain features for their classes
  - Fully compliant in regards to privacy and server location
  - Not quite launched yet but aiming at 2027 release and hopefully distributing through Lære

## New age of AI

This is one of the first projects I've started in this new age of AI-development, and it's been extremely exciting to see how far we are able to push ourselves now. We've utilized both Codex and Claude Code under development, along with some specialized skills for stuff like creating exercise drafts. By keeping a strict eye on the output of the agents and steering them in the right direction we've ended up with both a product and a codebase that we are confident in and proud of.

## Technologies

- Client: React Router, Typescript
- Payment: Stripe
- Infra: Cloudflare
- Auth: Clerk & Feide
- AI helper: OpenAI custom API integration (for now)
- Harnesses: Codex (Terra & Sol), Claude (mostly Sonnet)
